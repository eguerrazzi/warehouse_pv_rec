# Configuration

- `params/` — parameter registry (`base.yaml`) and its schema (`schema.yaml`). Filled in Phase 1.
- `scenarios/` — scenario manifests for experiments (`base.yaml`). Filled in Phase 6.
- `slurm/` — cluster settings (`cluster.yaml`: partition, account, wall time, memory). Values come from Ema in Phase 6; never hard-coded.
